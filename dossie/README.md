# Dossiê — João Gabriel Salvador Paiva

Base de conhecimento pessoal usada para montar currículos sob medida para cada vaga.
Cada arquivo é uma "fatia" da minha trajetória; o currículo de uma vaga é uma **seleção**
desses blocos, não um texto novo escrito do zero.

## Como usar

1. Leia a descrição da vaga e classifique-a em um dos perfis: **Backend**, **Mobile/Flutter**,
   **Full-stack**, **Dados/IA-NLP** ou **Pesquisa/Acadêmico**.
2. Abra [08-bullets-reutilizaveis.md](08-bullets-reutilizaveis.md) e escolha os bullets marcados
   com aquele perfil.
3. Monte o CV usando [templates/curriculo-base.md](templates/curriculo-base.md) e valide com
   [templates/checklist-por-vaga.md](templates/checklist-por-vaga.md).
4. Toda informação nova (nova entrega, número, prêmio, certificado) entra primeiro **aqui**,
   depois no CV.

## Convenções

- **Números sempre com fonte.** Se um número não tem origem verificável, ele fica em
  [09-fontes-e-lacunas.md](09-fontes-e-lacunas.md) e não vai para o CV.
- Datas divergentes entre fontes estão marcadas com `⚠` e listadas em
  [09-fontes-e-lacunas.md](09-fontes-e-lacunas.md).
- Este dossiê é público (o repositório é público). Não inclua dados sensíveis:
  documentos, endereço, dados de clientes ou contatos de terceiros.
